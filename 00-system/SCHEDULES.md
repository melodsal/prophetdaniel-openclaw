# SCHEDULES.md

## Daily AM trading brief

Schedule:

- Weekdays, 6:45 AM America/Los_Angeles

Purpose:

Prepare Victor for the trading day.

Focus:
1. TradingAccount open positions
2. TradingAccount tickers near entry
3. TradingAccount tickers near stop
4. TradingAccount tickers near targets
5. TradingView alerts
6. Dean/Discord/Twitter signals
7. Urgent FactorPortfolio or 42Macro issues only

Required updates:
- `05-market-notes/daily-am.md`
- `04-positions/open-positions.md` if state changed
- `01-indexes/tickers.md` if watchlist state changed
- `log.md`

## Daily PM trading brief

Schedule:

- Weekdays, 12:00 PM America/Los_Angeles

Purpose:

Summarize the trading day and prepare tomorrow's watchlist.

Focus:
1. TradingAccount position changes
2. Triggered alerts
3. Stops/targets/entries hit or close
4. P/L updates if data is available
5. Tomorrow's watchlist
6. Carry-forward notes

Required updates:
- `05-market-notes/daily-pm.md`
- `04-positions/open-positions.md` if state changed
- `04-positions/closed-trades.md` if trades closed
- `04-positions/p-and-l.md` if sufficient data exists
- `01-indexes/tickers.md`
- `log.md`

## Weekly trading review

Schedule:

- Sunday, 6:00 PM America/Los_Angeles

Purpose:

Review all three accounts.

Include:
- TradingAccount performance and open risk
- FactorPortfolio weekly update
- 42Macro weekly update
- closed trades
- lessons
- next week's watchlist
- incomplete data or manual review items

Required updates:
- `05-market-notes/weekly-review.md`
- `03-accounts/TradingAccount.md`
- `03-accounts/FactorPortfolio.md`
- `03-accounts/42Macro.md`
- `04-positions/p-and-l.md` if sufficient data exists
- `07-journal/trade-journal.md`
- `log.md`
